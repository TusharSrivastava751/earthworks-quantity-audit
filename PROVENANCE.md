# Provenance and responsible use

This is an original portfolio demonstration prepared with AI assistance in October 2026.
Code, sample datasets, test cases and example reports were created for this portfolio.
They do not represent a delivered employment project, client commission, production deployment,
professional approval, or evidence of business impact. All project identifiers and quantities are synthetic.

No employer/client drawings, survey coordinates, pricing, credentials or confidential files are included.
The code uses Python's standard library and makes no external API calls. References explain methods;
no third-party source code or proprietary CAD assets were copied into this repository.

The initial implementation and documentation were AI-assisted. Test results demonstrate behavior of
this version; they do not establish the portfolio owner's independent mastery. Before discussing it
in an interview, run the demo, understand the assumptions, and make and explain a small change.
Describe assistance honestly if asked. Future contributions should record what changed and why.

These examples support learning and quality-control discussions. Any real engineering application
needs project-specific criteria, reliable source data and review by a suitably qualified engineer.
